# 域名候选池与手动切换改造

2026-10-30，本地实现与验证完成，尚未上线。用户明确要求域名解除分组强绑定、手动选择服务器，并确认手动目标在健康期间保持固定，失败后自动切换。

## 契约

- 每个域名按服务器稳定 ID 保存独立候选集合；分组仅作为服务器筛选属性。
- 一次性事务迁移旧分组的全部资产至对应域名，包含未测试或失败资产；随后解除旧分组关联。迁移幂等，空组仍标记完成，失败可重试。
- 新域名允许空候选；保存配置与调整成员不直接写 DNS。旧 group API 仅作为一次性候选快照适配器。
- 候选列表与服务器选择器服务端分页，单次显式增删至多 5,000 个 ID。升级迁移使用 SQL，不受该交互批次限制，不在浏览器展开大组。
- 选择器展示统一连通性、下载/上传速率及测量时间；缺失与零分开表达。
- 手动切换必须为当前候选，并沿用现有健康判断。成功后原子保存当前 IP 与手动固定；失败不改变固定和当前指向，创建新记录失败不删除旧记录。
- 手动固定健康期间优先于常规排序；其故障时沿用既有排序选健康候选，成功切换后解除固定，不因原节点恢复而自动回切。
- 现有主控健康检查、失败阈值、周期、启停与定时边界、单条托管灰云 A 记录及非托管记录保护继续保留。
- 同步共享一个锁并重新读取域名状态；公开成员增删、域名修改和删除与同步串行，旧调度快照不能覆盖手动选择。

## 实施与验证

1. 存储、迁移、分页成员接口；验证多域名共享分组、空组、幂等和失败重试、分组变更隔离、无效 ID 原子失败与分页上限。
2. 选优、健康、同步迁至显式成员；验证固定优先、失败回落、固定解除、无健康保留现状、Cloudflare 部分失败和旧快照竞态。
3. 页面移除必选分组，新增候选管理及切换并同步确认；验证分页/跨页选择、重复点击、错误保留、固定状态与请求乱序。
4. 后端全量、前端构建/Vitest 与相关 Playwright；独立复审，记录已知问题边界。
